# Laptopy – موقع متجر اللابتوبات (دليل سريع)

مشروع Node.js كامل: كتالوج لابتوبات بالأسعار والمواصفات، سلايدر للسعر، مقارنة بيانية، **روبن** (مساعد AI بيرد بالعربي المصري والإنجليزي)،
لوحة أدمن محمية بـ **Google Sign-In**، وزراير واتساب وروابط إنستجرام وتيك توك وفيسبوك.

## التشغيل على جهازك

لازم Node.js 22 أو أحدث.

```bash
npm install
cp .env.example .env     # وبعدين عدّل الملف
npm run dev              # افتح http://localhost:3000
```

من غير أي مفاتيح الموقع بيشتغل: روبن بيرد بالمستشار المدمج، ولتجربة الأدمن محليًا حط `DEV_AUTH=true` في `.env`
(هيظهر زرار "Dev sign in" وسجّل بإيميل `ramezmilab@gmail.com`). **ماتفعّلوش على السيرفر الحقيقي أبدًا.**

## ربط Google Sign-In (دخول الأدمن الحقيقي)

1. ادخل على https://console.cloud.google.com/apis/credentials واعمل **OAuth client ID** من نوع *Web application*.
2. في **Authorized JavaScript origins** ضيف رابط موقعك، و`http://localhost:3000` للتجربة.
3. انسخ الـ Client ID في `.env`:
   ```
   GOOGLE_CLIENT_ID=xxxxxxxx.apps.googleusercontent.com
   ADMIN_EMAIL=ramezmilab@gmail.com
   ```
4. شغّل السيرفر من جديد. تبويب **Admin** بيظهر لحساب `ADMIN_EMAIL` بس، وأي حد تاني (مسجّل بحساب مختلف أو مش مسجّل)
   مش بيشوفه، والسيرفر نفسه بيرفض أي إضافة أو تعديل أو حذف منه.

## تفعيل الـ AI الكامل لروبن (اختياري)

حط `ANTHROPIC_API_KEY` في `.env`. من غيره روبن بيستخدم المستشار المدمج، وبيرد على العميل في كل الأحوال.
المفتاح بيفضل على السيرفر ومش بيوصل للمتصفح.

## الكتالوج الحالي: الـ 241 جهاز من شيت الأسعار بتاعك

الموقع بيبدأ بأجهزة `docs/laptopy_price_list.xlsx` (212 لابتوب و22 ديسكتوب و7 تاور).

- الأسماء اتنضّفت وبقت أسماء المنتجات الحقيقية: `hp840 g8` ← **HP EliteBook 840 G8**، `percision 7720` ← **Dell Precision 7720**،
  `P5510` ← **Dell Precision 5510**، `razer- 14` ← **Razer Blade 14**. والمعالجات والتخزين اتوحّدت (`i5-8th (U)` ← **Core i5 8th Gen (U)**، `256GB` ← **256GB SSD**).
- الموديل الواحد بمعالجات أو رامات مختلفة = نسخ مختلفة، وصفحة الجهاز بتعرض "Other versions of this model".
- نفس الموديل والمواصفات بسعرين مختلفين (وحدتين من مصدرين) اتحفظوا الاتنين، والصف المكرر بنفس السعر بيتشال.
- الديسكتوب والتاور مفيهمش بطارية ولا وزن، فالحقول دي بتتخفي وبتتسيب من المقارنة (مش بتتحسب صفر).
- لو عايز تعيد بناء الكتالوج من شيت جديد: `npm run build:seed` (بيشتغل أول مرة بس يتشغّل فيها الموقع).

## زرار "View photos"

على كل جهاز زرار **View photos** بيفتح في تاب جديد بحث صور جوجل **باسم المنتج بالظبط بين علامتي تنصيص**، مثلاً
`"HP EliteBook 840 G8" laptop`. عشان الأسماء اتصلّحت الأول، الصور اللي بتظهر بتبقى للموديل ده مش لموديل شبهه
(بتبان صور الموديل، مش بالضرورة صور الوحدة نفسها). اسمين مقدرتش أحدد موديلهم بالظبط: **HP 655S** و**Dell Pro**،
راجعهم. ولو عندك لينك صور خاص بجهاز، حطه في خانة **Photos link** من Admin ← Edit.

## إضافة الأجهزة من شيت إكسيل

من تبويب **Admin** ← **Import devices from Excel**:

1. اختار ملف الإكسيل. **شيت الأسعار بتاعك بيشتغل زي ما هو** (Type, Model, CPU, RAM, SSD | HDD, GPU, Display, Price, Photo)، أو نزّل القالب (`docs/laptopy-laptops-template.xlsx`).
2. هتشوف **معاينة** الأول (كام جهاز هيتضاف وكام هيتعدّل وأي صفوف فيها مشكلة)، ومفيش حاجة بتتحفظ لسه.
3. دوس **Import now**: الأجهزة بتظهر لكل الزوار فوراً.

- الماركة بتتعرّف من اسم الموديل لو مفيش عمود Brand.
- لو الصف مطابق لجهاز موجود بيتحدّث (استيراد نفس الشيت تاني مبيغيّرش حاجة، وتغيير سعر في الشيت بيحدّث الجهاز ده بس).
- العناوين تتكتب **بالعربي أو الإنجليزي**، وصف العناوين ممكن يبقى في أي مكان في أول 20 صف.
- الخلية الفاضية **مبتمسحش** بيانات موجودة. الصفوف اللي فيها مشكلة بتتخطّى وبتتعرض برقم الصف.
- علّم **"Also remove devices that are not in this file"** لو عايز الموقع يبقى زي الشيت بالظبط (بيطلب تأكيد).
- صور الملفات (JPG وPNG وWebP لحد 5MB، و10 صور للجهاز) بتترفع من **Edit and photos**.

## صفحة الجهاز

دوس على أي جهاز في الصفحة الرئيسية تفتحلك صفحته: معرض صور (وبتفتح بحجم الشاشة كلها)، المواصفات كاملة مقسّمة، الوصف،
زرار الطلب على واتساب، "Ask Robin about it"، ولابتوبات مشابهة.

## اللابتوب ثلاثي الأبعاد في أول الصفحة

مرسوم بالكود بـ three.js (`assets-src/laptop-scene/main.js`): جسم ألومنيوم، كيبورد بمفاتيح حقيقية، سماعات، تراك باد، مفصلة وشاشة زجاج.
الغطاء بيفتح ببطء والشاشة بتنوّر وبتنعكس على المفاتيح، وبعدين يظهر اللوجو واسم المحل (من `config/store.json`).
لو عدّلت في ملف المشهد شغّل `npm run build:scene`. على الأجهزة اللي مفيهاش WebGL بتظهر صورة ثابتة للابتوب بدل الحركة.

## تعديل بيانات المحل

ملف `config/store.json`: الاسم، السلوجان، التليفون، رقم الواتساب (بكود الدولة من غير +)، العنوان، روابط السوشيال.
اللابتوبات بتتدار من تبويب Admin.

## النشر على السيرفر

- اضبط `NODE_ENV=production` و`SESSION_SECRET` (طويل وعشوائي) و`GOOGLE_CLIENT_ID` و`ADMIN_EMAIL`.
- لو الاستضافة بتحط HTTPS قدام التطبيق: `TRUST_PROXY=true`.
- اربط **قرص دائم (persistent disk)** وخلّي `DATA_DIR` يشاور عليه، وإلا اللابتوبات والصور المرفوعة هتضيع مع كل نشر جديد.
- ضيف رابط موقعك الحقيقي في *Authorized JavaScript origins* في Google.
